# EMbrella Next.js and React Frontend

### Install Dependencies

1. `cd` into the `frontend` directory.
2. Run `yarn`.

### Run Frontend

1. `cd` into the `frontend` directory.
2. Run `yarn dev`.
3. Open browser at http://localhost:3000/next.

### Run Tests

1. `cd` into the `frontend` directory.
2. Run `yarn test`.
