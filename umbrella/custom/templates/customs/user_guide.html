User Guide

Welcome to Embrella

This guide will help you understand how to use the platform.

  • Login with your credentials.
  • Use Workflow Management to start new tasks.

Search Filters

Search filters allow you to find and manage stored data.

  • Use Grids Search to find cryo grids.
  • Use Processing Runs to filter by metadata.

Run Workflow

This section explains how to process data.

  • Use Aretomo Run to process cryo-EM data.
  • Use Metadata Fetcher to extract metadata for processing.

Metadata Fetcher

Learn how to retrieve metadata for your sessions.

  • Go to the Metadata Fetcher section.
  • Enter your Session ID and Run ID.
  • Click Fetch Metadata.

Final Steps

Now you're ready to use Embrella!

  • Use the search filters to explore stored data.
  • Start new workflows using the Run Workflow section.
  • If you need help, contact support.
