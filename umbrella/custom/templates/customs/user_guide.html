User Guide

Follow these steps to use Embrella:

  • Login with your credentials.
  • Use **Workflow Management** to start new tasks.
  • Use **Search Filters** to find specific data.
  • Use **Run Workflow** to start processing jobs.
  • For **Metadata Fetching**, go to the **Metadata Fetcher** section.
  • Click the **Go Back** button to return to the main page.
